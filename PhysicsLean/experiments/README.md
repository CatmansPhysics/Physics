# PhysicsLean Experiments

This directory contains reproducible Python experiments that accompany the Lean
formalization.

## Rules

- Experiments provide computational evidence and toy-model exploration only.
- Experiments do not replace Lean proofs.
- Each experiment must be linked to a chapter range and a package.
- Reports written under `reports/` must state scope and limitations.

## Phase 0 content

Phase 0 only includes a smoke-test package layout so the workspace can be
validated before the structural-core port begins.
