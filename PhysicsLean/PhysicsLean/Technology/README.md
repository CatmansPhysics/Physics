# Applied Technology Formalization

This namespace is reserved for applied technology programs derived from the main theory but maintained as separate formalization packages.

## Current program namespaces

- `AGT/`: antigravity technology.
- `FTL/`: faster-than-light transport technology.
- `Materialization/`: materialization technology.

## Rule

Applied technology files belong here only after their terminology and statement inventory have been normalized against the canonical manuscript backlogs in `docs/Technology/registry/technology_program_backlog.md`.
