# Soft S1-M1 Array Closeout Package

This package upgrades the earlier single-cell `soft_s0_m1` into a medium-specific **16x16**
glassy chemical-memory witness array and closes Stage 2 of the roadmap numerically.

## Deliverables
- `baseline_cycles.csv`
- `long_repeatability.csv` (1024 cycles)
- `sweep_summary.csv`
- `summary.csv`
- plots

## Numerical closeout targets
- mean array accuracy >= 0.95
- worst margin > 0.30
- failed-cell fraction < 0.10
- memory criterion satisfied
- glass criterion satisfied
