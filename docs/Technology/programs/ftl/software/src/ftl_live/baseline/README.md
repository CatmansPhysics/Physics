# ftl_final_baseline_package

Frozen numerical baseline for the FTL project.

## Included baseline layers
- soft_s0_m1
- hard_h0_m1
- hard_h1_m2
- orchestrator
- portfolio
- profile optimizer
- adaptive policy

## Key files
- `combined_results/master_baseline_metrics.csv`
- `combined_results/regression_checks.csv`
- `combined_results/freeze_summary.csv`
- `combined_results/freeze_summary.json`

## Purpose
This package is the frozen reference point for the remaining roadmap stages:
1. soft S1-M1 array numerical closeout
2. hard H1-M2 bench numerical closeout
3. integrated mission campaign closeout
4. medium down-selection
5. prototype-readiness dossiers
